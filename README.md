# Sistema de Cadastro de Produtos em Python

## 📌 Objetivo do Projeto

Este projeto foi desenvolvido em Python com o objetivo de praticar operações de leitura e escrita em arquivos, além da manipulação de dados através de um sistema de gerenciamento de produtos executado pelo terminal.

O sistema permite cadastrar, listar, consultar e excluir produtos armazenados em um arquivo de texto, simulando funcionalidades básicas encontradas em sistemas de estoque e controle de inventário.

## 🎯 Funcionalidades

* Cadastro de novos produtos.
* Listagem de todos os produtos cadastrados.
* Consulta de produtos por linha.
* Exclusão de produtos por linha.
* Armazenamento permanente dos dados em arquivo `.txt`.
* Interface interativa através do terminal.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram praticados os seguintes conceitos:

* Programação em Python.
* Estruturas condicionais (`if`, `elif` e `else`).
* Estruturas de repetição (`while` e `for`).
* Manipulação de arquivos utilizando a função `open()`.
* Modos de abertura de arquivos (`r`, `w` e `a`).
* Leitura de dados com `readlines()`.
* Manipulação de strings com `split()` e `strip()`.
* Armazenamento persistente de informações.
* Organização de menus interativos.
* Lógica para operações CRUD (Create, Read e Delete).
